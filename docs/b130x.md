# BlackVue B-130X

Status: hardware-observed charging and loaded-discharge telemetry on firmware **1.61**, returned identity **B-130X**. Its observed status fields use the same extended legacy layout as [B-130A 1.61](b130a.md). This establishes that layout on these revisions, not universal model or settings compatibility.

## Implement a client

1. Recognize advertisement prefix `130X` or `B-130X`. Treat any remaining suffix as a private identifier.
2. Discover `FFF0`, subscribe to response `FFF1`, and use writer `FFF2` with its actual GATT properties; write without response is supported by the observed transport.
3. Send identity query `43 06 00 52 17`; match returned `B-130X` and firmware integer 161 before selecting this map. Identity model is six ASCII bytes at offsets 10–15; firmware is BE16 at 4–5.
4. Send status query `43 06 00 51 14`. Use the [shared framing and status map](blackvue-legacy.md#status-reply-51): firmware 161 uses the extended branch with BE16 input/output voltage at 23/25, each divided by 10. Current remains BE16 at 14/16 divided by 1000; reported runtime is BE16 minutes at 5. Offsets are zero-based complete-frame positions.

Observed state low nibble at 20: **1 charging**, **3 discharging under load**. Subscribe before querying, reassemble notifications and reset identity/stream state after reconnecting. Incoming checksum semantics remain unverified; the outgoing query trailer is XOR.

## Charging-mode current limitation

The discharge-current field can report zero while the battery is charging and a connected dashcam is running. Do not treat that zero as proof of no camera power or measured zero total output watts. The manufacturer app hides the B-130X output section during normal charging when neither its low-input nor high-input flag is set. Exact behavior in those flagged modes is not hardware-verified.

After input disconnect, the observed loaded-discharge replies report nonzero output current and runtime. Calculated power is voltage multiplied by current; distinguish a reported discharge-current-based calculation from a complete measurement of charging-mode camera consumption. Runtime is the battery's estimate, not guaranteed recording endurance. Capacity is configured/device-reported, not measured health or usable energy.

## Scope and unknowns

Other firmware, full/protection states, input-mode flags and current reporting in all charging paths remain unverified. Beep/configuration command source context is in the [shared reference](blackvue-legacy.md#configuration-commands); no B-130X settings write or persistence behavior has been hardware-verified. Do not infer configuration compatibility from a shared status map.
