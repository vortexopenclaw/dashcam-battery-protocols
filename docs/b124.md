# BlackVue B-124

Status: hardware-observed telemetry on firmware **1.44**, returned identity **B-124**. The [shared wire protocol](blackvue-legacy.md) defines UUIDs, requests, framing and offsets. This revision uses the classic input/output voltage bytes at offsets 11 and 12.

## Implement a client

1. Discover `FFF0`, subscribe to `FFF1`, write without response to `FFF2`.
2. Send identity request `43 06 00 52 17`; read firmware BE16 at offset 4 and model ASCII at offsets 10–15.
3. Match `B-124` within the selected device family, then send `43 06 00 51 14`.
4. Firmware 1.44 status is 23 bytes: 18 payload bytes plus 5 framing bytes. Decode classic voltage bytes 11/12, current BE16 at offsets 14/16 and the remaining [shared status fields](blackvue-legacy.md#status-reply-51).

Use the [shared configuration commands](blackvue-legacy.md#configuration-commands) for source-derived beep/capacity handling. B-124X identities and other firmware branches are source-derived rather than separately device-tested. Capacity is a configurable protocol value, not measured battery health.
